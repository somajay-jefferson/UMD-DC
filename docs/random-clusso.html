What it appears to be

CLUSSO for correlated features

Random CLUSSO belongs to a separate manuscript by the same first author. The README inside Supplemental_Code.zip titles it Analysis of Correlated Image Features using Scalar‑on‑matrix, and describes a setting where the feature matrices have differing numbers of rows and the image features are correlated with one another.

The motivation is stated plainly in the CLUSSO paper's own discussion: the lasso tends to select only one of a group of features that are correlated with each other and with the outcome. It proposes the random lasso of Wang, Nan, Rosset & Zhu (2011) as a replacement inside the CLUSSO objective. Random CLUSSO appears to be exactly that substitution.

The data generation gains a correlation parameter, rho, between informative predictors, and leans on the MixMatrix package to draw correlated tubules from a matrix‑variate distribution.

Why it matters here

It already contains a bootstrap

Random_CLUSSO_non_mainfunctions.R defines bootstrap.estimates(), and a single call does three nested resamples: it bootstraps subjects, bootstraps tubules within each resampled subject, and subsamples the feature columns — uniformly on the first pass, then with probability proportional to an importance measure on the second. That two‑stage structure is the random lasso.

This is not merely a sibling method. PS‑Fdr's outer machinery is itself a bootstrap wrapped in a permutation loop. Composing it with Random CLUSSO would nest a bootstrap inside a bootstrap inside a permutation — a compute problem, and a harder conceptual one about what the resulting selection frequency is actually measuring. See FDR‑CLUSSO.

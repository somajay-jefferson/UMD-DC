UMD DC · method notes

Unbalanced matrices,
and what you may believe

Two algorithms drawn end to end, and the open question of whether one can be wrapped around the other.

Overview CLUSSO Random CLUSSO PS-Fdr FDR-CLUSSO

Some data arrives as a matrix per subject rather than a vector. Each row is one measured object and each column is one feature. The first mode is unbalanced — subject i supplies pi objects and that count varies freely — while the second is balanced, the same q features on every object. Cells per sample, events per flow-cytometry run, segmented objects per image: the shape recurs, and it breaks every scalar‑on‑matrix method that expects a balanced design. CLUSSO handles it, given a continuous scalar outcome.

Separately, cross‑validated penalized selection is known to over‑select badly — in one benchmark roughly nine of every ten reported discoveries were noise. PS‑Fdr is a procedure that puts a false discovery rate guarantee on penalized selection without needing p‑values.

These notes work through both algorithms in full, then ask whether the second can be wrapped around the first — an extension the CLUSSO paper's own discussion proposes but leaves unbuilt.

Method · written up

CLUSSO

Pool every object, cluster them, average within subject and cluster, then fit an alternating structured lasso. Includes a twelve‑subject example run end to end through the real implementation.

 Method · written up

PS‑Fdr

Bootstrap stability selection, a permutation‑calibrated null, a SAM‑style normalization and a step‑down cutoff that bounds the fraction of selected variables expected to be false. Includes a thirty‑feature example run end to end through the real implementation.

 Open problem

FDR‑CLUSSO

Substituting CLUSSO for the lasso inside PS‑Fdr. The interface lines up on a single line; three obstacles do not. Where it breaks, ranked, and what still has to be decided.
